• Never commit API keys, tokens, or passwords to any repository, public or private. Keep secrets in environment variables or in a .env file listed in .gitignore, and turn on GitHub secret scanning / push protection for your account. The first leaked key is a learning moment. After that it is a grading deduction.
  • Run agents with least privilege. Do not run an agent in bypass-permissions ("YOLO") mode on a machine or directory holding data you care about. Use a dedicated project directory, rely on git for recovery, and (in MP3) write hooks that deny destructive commands.
  • Keep confidential data out of agent context. Do not paste other people's private information, unpublished third-party research, or College-internal data into commercial AI services.
  • Report any accidental leak to the instructor immediately so we can rotate keys. There is no penalty for prompt disclosure.
